# Lab 4 – CNN and Transfer Learning

## Overview
This lab explores CNN architectures and transfer learning using the CIFAR-10 dataset with PyTorch.

## Tasks Covered
- CIFAR-10 dataset preparation and visualization
- Transfer learning using MobileNetV2
- Model training and validation
- Performance evaluation using accuracy, precision, recall and F1-score
- Hyperparameter study
- Comparison of CNN architectures: LeNet-5, AlexNet, VGG16, GoogleNet and ResNet50
- Discussion of CNN and transfer learning concepts

## Technologies Used
- Python
- PyTorch
- Torchvision
- Hugging Face Datasets
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
CIFAR-10 containing 10 classes of 32×32 colour images.

## Hardware
Experiments were performed using GPU acceleration when available.

## Results
The experiments compare different CNN architectures and hyperparameters based on classification accuracy, number of parameters and training time.
