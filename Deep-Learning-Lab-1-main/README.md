# Single Layer Perceptron

This project uses the Banknote Authentication Dataset from the UCI Machine Learning Repository to create a Perceptron Neural Network from scratch using Python. Data preprocessing, exploratory data analysis, model training, and performance evaluation are all included in the full machine learning pipeline.

Additionally, the notebook provides a practical grasp of the Perceptron learning method by comparing the custom Perceptron with Scikit-learn's implementation, visualising training progress, and analysing the impact of various learning rates and activation functions.
